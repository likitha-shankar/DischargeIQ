## The pattern is already in use

Dr Liebovitz's written review was worked through exactly this way -
`docs/LIEBOVITZ_REVIEW_RESPONSE.md` tracks each of his items to a status and,
where closed, to the commit that closed it. That file is the template for
what this task produces once 4.2 runs.

Worth noting for the eventual write-up: two of the fixes prompted by that
review took **three attempts each**, and the intermediate attempts were
wrong in ways that looked right. A fix pass that records only the final
commit loses the part a reviewer most needs to see. Trace the attempts, not
just the closure.
