# Task 2.3 - Gamification Strategy Document ✅

**Deliverable:** a one-page strategy document making honest claims.

**Artifact:** `docs/GAMIFICATION_STRATEGY.md`, rewritten 31 Jul 2026.

**Shape:** one-page summary first, then a per-step patient walkthrough, then
build status matching what actually ships.

## The rewrite, and why it was needed

The first version described the intended design. The rewrite describes only
what is built, and marks retired ideas as **retired** rather than leaving
them reading as live. A strategy document that lists unbuilt features
alongside built ones cannot be used to answer "what does the app do", which
is the only question anyone asks it.

## What ships

Stars per section, follow-ups added to the device calendar, and levels.

**Deliberately absent: leaderboards and timers.** Both were considered and
rejected. A patient just home from hospital should not be ranked against
other patients, and a timer on a comprehension quiz measures anxiety rather
than understanding. The document says so explicitly, because "we chose not
to" is more useful to a reader than silence.
